# BlogPulse

A modern Blog Management System built using HTML, CSS, JavaScript, Node.js, and Express.js.

## Features

- Create Blog
- View Blogs
- Edit Blogs
- Delete Blogs
- Modern Responsive UI
- REST API
- Fetch API Integration

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
